\noindent\textbf{A motivating test on hosted models.}
Table~\ref{tab:frontier-motivation} evaluates the same five domains
at all three levels without additional training. On Level-3 Graph,
$99.8--100.0\%$ of answers are correct, yet $92.7--99.4\%$ of correct pairs repeat a mode
(uniform reference: $19.0\%$). This motivates measuring breadth alongside accuracy;
it does not identify a training cause or a model-size effect.

Concentration does not increase uniformly with the benchmark level:
levels use different tasks and do not guarantee increasing difficulty
for each deployment. Refusal-heavy cells also mix output availability
with correctness. Macro accuracy can mask domain failures: GPT-5.6 Sol
Python strict accuracy is only 8.5/9.4\% at Levels 2/3.
A separate Opus 5 Python follow-up rewrites the task
as a direct arithmetic-expression request and omits the system message.
Refusals fall from 2,454 to 3 of 3,072 draws; after the frozen formatting
normalizer, all 3,069 non-refused answers pass, while correct-pair collision
remains 79.9--85.7\% (Appendix~\ref{app:hosted-python-prompt}).
This exploratory condition is kept separate from the original table.
