# E49I executable algorithm-signature veto calibration

**Status: FROZEN BEFORE ANY E49I 72B REQUEST — 2026-07-24**

## Motivation

E49G's partial and subsequently finalized evidence rejected all four manually
verified distinct pairs.  It defined equivalence at the level of a minimal
mathematical identity, which collapses the executable alternatives that the
canonical bank is intended to model.  For example, a theorem shortcut and an
independent constructive factorization can share a consequence while still
requiring different policy actions.

E49I changes the canonical object from the minimal mathematical consequence
to the minimal **executed algorithm signature**.  It does not restore any
earlier automatic novelty claim.  It is calibrated on the already frozen,
manually labeled 29-pair packet and remains followed by a new blinded manual
audit on E49H's unseen curated cohort.

## Signature boundary

Before comparing routes, the judge removes prose, action IDs, declared kernel
labels, arithmetic bookkeeping, redundant checks, and unnecessary detours.
It retains each route's ordered primitive operations: the theorem invoked,
object constructed, invariant established, search/counting space traversed,
representation-specific algorithm executed, and extremum/globality proof.

Routes are equivalent when the remaining signatures differ only by ordinary
algebra, notation, action granularity, unit conversion, relabeling, reordering
independent bookkeeping, or a different representation of the same primitive
calculation.

Routes are distinct only when both are sound and each executes a necessary
primitive absent from the other.  In particular:

- a genuine theorem shortcut can differ from independently constructing the
  answer by factorization;
- a direct radix grouping algorithm can differ from conversion through a
  decimal intermediate followed by repeated division;
- differentiating a generating function can differ from shifting and
  subtracting the target series;
- direct counting of an interior product space can differ from counting a
  larger space and subtracting a separately characterized boundary.

These positive boundaries do not make superficial differences distinct.
Calling multiplication a Cartesian-product bijection is equivalent; solving
the same inverse-variation invariant by a ratio or a named constant is
equivalent; decimals versus fractions are equivalent; a unit detour is
equivalent; and an unsound or incomplete route cannot establish novelty.

## Frozen decision

Each pair receives four temperature-zero assessments:

1. algorithm-signature editor, A then B, seed `493201`;
2. algorithm-signature editor, B then A, seed `493202`;
3. false-new prosecutor, A then B, seed `493211`; and
4. false-new prosecutor, B then A, seed `493212`.

An assessment votes distinct only when both routes are sound, the primitive
signatures differ, no routine signature translation exists, the difference
is not labels/granularity only, and each route has a nonempty different
exclusive operator.  The pair prediction requires at least three of four
distinct votes.  Malformed or incomplete assessments vote non-distinct.

Calibration passes only with:

- zero false-new predictions across all 25 manually non-distinct/unsound
  pairs;
- all three hidden equivalent controls rejected;
- at least three of four manually distinct pairs recovered; and
- all requests complete.

No E49H policy training is authorized by calibration alone.  The unseen
curated cohort still requires independent trace execution, this veto, sealed
manual labels, zero manual false-new, and the frozen support thresholds.
