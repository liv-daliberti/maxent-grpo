## Frozen gates

Each route receives the same independent literal-executor and adversarial
action-checker audits as E49H. A pair proceeds only if all four route audits
pass. It then receives the four frozen E49J restricted-MathIR parses and is
called distinct only by four-way unanimity of the deterministic local
signature comparator.

The exact E49J calibration report is required and has SHA-256
`3400db77d6da7572395fe4d40b03ec59b792e2682c18c49ce861d32206bab3db`.
That calibration completed 116/116 requests with zero false-new predictions,
25/25 true negatives, and 4/4 true positives.

The buffer deliberately uses algorithm pairs expressible in the already
calibrated ontology: closed-form combinations versus exhaustive enumeration,
symbolic interval bounds versus literal testing, prime-exponent construction
versus Euclidean/divisor scans, binomial formula versus probability dynamic
programming, arithmetic mean versus endpoint-series solving, prime-square
characterization versus divisor enumeration, factor constraints versus
integer-ratio scans, and block counting versus anchored permutation scans.

## Downstream gate

Automated passage remains necessary but insufficient. E49K survivors join
E49H survivors in one sealed, order-randomized manual packet containing
hidden equivalent controls. Training remains blocked unless manual false-new is exactly zero,
every retained route is sound and self-contained, combined
support reaches at least ten train and ten evaluation rows, no toy row has
zero support, and every rendered prompt fits the frozen context limit.
